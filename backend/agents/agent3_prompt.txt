SCORING METHODOLOGY
Calculate the metabolic_interference_score (0 to 1, where 0 = no predicted interference, 1 = severe predicted interference) using these components:
1. Enzymatic Degradation Risk (0-1) — formerly "CYP ortholog degradation"; renamed because most gut bacterial drug metabolism occurs via non-CYP enzymes (Zimmermann et al. 2019). This score covers any bacterial drug-metabolizing enzyme ortholog acting on the drug before systemic absorption.
For each drug, sum the interference from all enzyme ortholog matches (CYP or non-CYP):

Per match: (evidence_tier_weight) × (abundance_factor)
Evidence tier weights: Tier 1 = 1.0, Tier 2 = 0.5, Tier 3 = 0.2
Abundance factor: abundance_pct / 20 (capped at 1.0, so 20%+ abundance = maximum factor)
Sum all matches, cap at 1.0
A Tier 1 ortholog match (specific drug-microbe pair experimentally tested) at >5% abundance should score ≥0.5 on this component alone. Tier 2 matches (enzyme present, drug class is substrate, specific pair not tested) accumulate more gradually.

2. Enterohepatic Reactivation Risk (0-1)

0.0 if drug glucuronidation = false
If glucuronidation = true: sum (beta_glucuronidase_abundance × evidence_tier_weight × efficiency_factor) over CONFIRMED GUS producers only (E. coli, B. fragilis, R. gnavus). DO NOT include E. faecalis — it is not a confirmed drug-reactivating GUS producer.
efficiency_factor: 1.0 for E. coli and B. fragilis; 0.5 for R. gnavus (its L1-loop GUS processes drug-glucuronides less efficiently per Biernat et al. 2019, Sci Rep).
If glucuronidation is a MAJOR pathway (e.g. Venlafaxine ODV): multiply by 1.5, cap at 1.0
Tier 1 GUS producer at >5% abundance for an antidepressant with major glucuronidation = minimum 0.4 risk

3. Metabolic Pathway Redundancy (0-1) — PROTECTIVE factor

Count the number of distinct CYP enzymes that metabolize this drug
1 enzyme = 0.0 (no redundancy, high risk if compromised)
2 enzymes = 0.3
3 enzymes = 0.6
4+ enzymes = 0.8
This REDUCES the final interference score

4. Active Metabolite Buffer (0-1) — PROTECTIVE factor

0.0 if no active metabolite exists
0.3 if a weakly active metabolite exists
0.6 if an equipotent active metabolite exists (e.g., Venlafaxine → ODV)
0.8 if active metabolite has very long half-life (e.g., Fluoxetine → norfluoxetine)
This REDUCES the final interference score

Final Score Calculation
metabolic_interference_score = (ortholog_degradation_risk × 0.45 + enterohepatic_reactivation_risk × 0.35) × (1 - metabolic_pathway_redundancy × 0.3) × (1 - active_metabolite_buffer × 0.25)
Cap the final score between 0 and 1.
GRAPH CONSTRUCTION RULES

Create one node per unique drug, enzyme, taxon, and metabolite.
Node IDs must be deterministic: drug_{lowercase_name}, enzyme_{name}, taxon_{genus_species}, metabolite_{name}.
Every edge must have an evidence_tier and confidence_weight.
confidence_weight = evidence_tier_weight (1.0/0.5/0.2) × abundance_factor for microbiome edges.
Edges between drugs and human enzymes are always Tier 1 (from curated PK data).
Run a CONSISTENCY CHECK: if Agent 2 claims an ortholog match for an enzyme that Agent 1 did NOT list for that drug, DROP that edge and note it in the edge properties as "dropped — inconsistent with PK data."
